Plan mode with habit blocks — mockup only

D6: time blocks hold habits only, and Plan mode gets a mockup, not a build, unless the person says so at the Phase 1 review. Plan mode today (§0.6.5, step 7b): an hour grid, events solid, estimated tasks dashed, the now line, the unplanned rail at the foot. Proposed here: the day's habit blocks drawn behind the grid as neutral bands (alternating surface2), their names at the right edge with the block's hue as a small mark beside each name — the only place a block's colour appears (the person's rule, 2026-09-29); habits with a set time drawn at it in the habit colour; each block's flexible habits as one pill under the block's name — 4 any time — which lists them, checked or not, when tapped. Tasks and events are untouched — a block is a habit's container, never a task's, so nothing snaps to it.

What changes, what does not

New: the bands, their names, the any time pill under each name, and a toggle (Habit blocks) in the Plan header's sub-row, on by default, off to see the grid as it is today.

Unchanged: events, estimated tasks, the now line, the logged strip along the gutter, both long-press drags. Dragging a task over a band does not put it in the block — blocks hold habits only (D6).

Habits with a set time sit at their time in the habit colour, one row high, so a day of Water every three hours reads as a column of short marks rather than six boxes. A habit with a length (Dentist, 30 m) takes its length.

An interval habit with no block (Water the plants) joins the Not planned rail, marked as a habit — the rail is where Plan mode already puts what has no time.

Changed after the first render: the flexible habits were first a row of chips across the top of each band; with four of them the row wrapped onto Morning's 07:00 Water, and a block starting half an hour before a set time has no room for a second line. The pill keeps the grid for what has a time.

Not in the mockup, to decide if this is built: whether a flexible habit can be dragged to a time in Plan mode (it would become a scoped edit, "Apply this change to…"), and whether the band names crowd the grid on the desktop's narrower day columns.
