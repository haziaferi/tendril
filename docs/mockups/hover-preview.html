Hover Previews

B§13.6 #3 — hold the pointer on an @mention, a mention block, a block reference or a Road Map node and a card shows what it points at: the page's kind and title, when it was edited, its first lines. Obsidian's page preview and Notion's, without the modifier key; a block reference previews the line in its context, live. Desktop only — a finger has no hover.

  1. The card: 320 dp, the kind's glyph, the title, edited 2 h ago at the right; up to six lines of the page's blocks in order (a checkbox as ☐/☑, a heading bold, a mind map or canvas as a count), each ellipsised; a footer with what is left and that a click opens.
  2. When: 500 ms after the pointer settles on the target; gone when it leaves the target or the card; never on Touch. The target shows a 1.5 dp accent outline while the card is up.
  3. A block reference previews its source line marked, with the line before and after — the same live text the card already shows, now with its neighbours.
  4. A database previews its Table: the view, the row count, the visible columns, the first rows; a canvas its card count and the first cards' text.
  5. Click anywhere on the card opens the page (Shift+click in a window, Ctrl+click beside — the tree's chords).
