Pop-out Windows

B§13.6 #6 — a page in its own OS window beside the main one: the same editor, its own back stack, its own ⋯; the main window keeps the tabs, the tree, the timer and the shortcuts card. Desktop only. Ink at 1400 × 820, the OS chrome drawn flat.

  1. A pop-out is one page and its history: the page bar (the kind's glyph, the title, ⋯), the body; a link inside it pushes inside it and Escape pops; Escape at the root closes the window. No rail, no tree, no timer strip.
  2. Opened from the page's ⋯ (Open in a window), the tree row's menu, or Shift+click on a row; the page stays open in the main window. Closed by the OS × , Ctrl+W, or Open in the main window (which shows it there and closes here).
  3. Remembered: the open pop-outs and their frames come back on relaunch (popout_pages, popout_frame_<id>); a new one opens at 600 × 520 cascaded 32 px from the last.
  4. The tree marks a popped-out page with ⧉ at its row's end (the shelf's ring is the shelf's).
  5. Any kind: a page, a database (its Table), a canvas. Two windows on one page are two ViewModels over one database — edits in one appear in the other.
