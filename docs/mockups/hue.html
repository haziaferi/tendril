Where it shows: the Road Map's node fill (the third hue's tint until now), a database date's chip and dot on the calendar (a database is a calendar), and the database's glyph wherever it is drawn. The same control colours a canvas card or frame — Obsidian's canvas measured live today: a node's colour row is none + six presets (red · orange · yellow · green · cyan · purple, 20 px discs at a 29 px pitch, JSON Canvas's "1"–"6") + a custom wheel; a coloured node is a tint fill with its border in the hue. One control for both: a hue bar 0–360° with the six as marks under it, Default / None above; the swatch reads the solved colour and its contrast. Nothing stored but a hue (an integer, null for the default) — the register solves it on each ground, as labels are.
