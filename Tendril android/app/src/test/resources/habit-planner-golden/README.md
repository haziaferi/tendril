# Reference cases for the scheduling engine

Generated by `tests/make_golden.py` from `planner/assets/engine.js`, the planner's single scheduling engine. Each JSON file holds an input `model`, the `mondays` computed, and the `expected` result per day: the blocks with their effective times, every occurrence (habit id, its number within the day, block, set time, minutes, tag) and the two structural flags Tendril keeps: `flag_outside` (a set time outside every block) and `flag_overlap` (blocks overlapping).

Left out on purpose, because Tendril drops them: ordering by priority inside a block, the daily limit and the block-over-capacity flag.

A block runs from its start up to, not including, its end: 09:00 belongs to the block starting at 09:00.

Cases: `base-rules`, `edit-occurrence-block`, `edit-day-series-shift`, `edit-week-weekdays-time`, `edit-from-minutes`, `edit-skip-delete-pause`, `edit-move-to-other-day`, `edit-series-slot-to-time`, `block-overlap-flag`, `block-boundary-moved`.
